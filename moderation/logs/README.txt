这个文件夹保存群聊违禁内容检测和入群申请审核的记录。

机器人运行时每天会生成这些文件：

  warnings-YYYY-MM-DD.log       违禁内容警告，方便直接打开阅读
  warnings-YYYY-MM-DD.jsonl     违禁内容警告，结构化记录，方便脚本统计
  join-reviews-YYYY-MM-DD.log   入群申请审核（开启 join_review 后才会生成）
  join-reviews-YYYY-MM-DD.jsonl 入群申请审核（开启 join_review 后才会生成）

违禁内容警告包含：时间、群 OpenID、成员 OpenID（如果 API 提供了昵称也会一起记录）、
消息 ID、违规类型、触发关键词、原消息内容、是否撤回成功、是否发送警告等。

入群申请审核包含：时间、群 OpenID、申请人 OpenID / 昵称、申请 ID、申请来源、
入群验证方式、验证消息或管理员问答、大模型评分与结论、理由、本地群规命中情况、
标准答案匹配数量、标准答案来源（全局 / 群专属 / 合并）、是否自动通过/拒绝、
审批接口是否成功、是否发送群通知等。管理员配置的标准答案本身不会写进普通审核记录。

注意：入群审核记录里可能包含申请人填写的问答内容，属于个人信息，请妥善保管，
不要随意公开。日志目录和规则文件都可以在 config.json 的 moderation 部分修改。
